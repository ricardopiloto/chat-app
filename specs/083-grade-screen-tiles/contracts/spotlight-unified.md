# Contract: Spotlight on unified grid

| ID | Rule |
|----|------|
| SP-01 | Spotlight available only in Grade and only for accounts with an active screen tile. |
| SP-02 | Activating spotlight enlarges that **screen** tile locally inside the unified grid; other tiles remain in the same grid (no screen/camera bands). |
| SP-03 | Spotlight is not synced to other clients. |
| SP-04 | When spotlighted sharer stops sharing → spotlight clears; no auto-pick of another screen. |
| SP-05 | Camera tiles must not offer spotlight. |
