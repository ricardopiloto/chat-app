01 // Pilares de Fundação

Princípios de Design da Mesa

🕯️

1. O Acolhimento da Mesa

Tons calorosos de terracota, toques de âmbar e pergaminho que evocam a atmosfera intimista de uma sessão presencial em volta de uma mesa, evitando a frieza metálica de ferramentas enterprise ou o neon agressivo de streamers de esports.

🔒

2. Confiança Criptográfica Tranquila

A criptografia ponta-a-ponta (E2EE) é o padrão sagrado. O design torna a custódia das chaves e os estados de segurança (ligado/desligado) visíveis, compreensíveis e serenos — nunca alarmistas ou intimidadoramente técnicos.

🎬

3. Rigor de Estúdio Broadcast

Layouts nomeados para composição de câmeras (Mestre em Destaque, Painel, Faixa), indicadores precisos de fala, partilha de tela estelar e controles dedicados no painel do usuário que nunca invadem a área do palco de vídeo.

07 // Matriz de Telas & Especificações

Mapeamento Arquitetural de 100% dos Ecrãs

3.1 Autenticação & Onboarding

Completo
  • Ecrã login/registo em 2 colunas com aviso self-hosted
  • Campos handle (@), password (8 chars + toggle)
  • Botão que adapta rótulo: Entrar / Registar / Desbloquear
  • Fluxo de desbloqueio de cofre de identidade local
  • Ecrã de convite com prévia sem sessão e registro inline

3.2 Servidores

Completo
  • Diálogo Criar Servidor com chave gerada + checkbox obrigatória
  • Definições (/settings): Grupo Pessoas, Papéis, Servidor
  • Permissões de Cargos (Geral, Texto, Voz) com toggle read-only para sistema
  • Upload de imagem JPEG/PNG/WebP até 1 MiB
  • Mensagem de boas-vindas com canal selector + template

3.3 Canais & ACL

Completo
  • Criar canal com seletor emoji, visibilidade e custódia para voz
  • Renomeação inline com normalização de hífen (limite 32 chars)
  • Construtor de regras ACL com Inspetor de Acesso resolvido
  • Silenciar membro com timeouts (5/10/15/30 min)
  • Roster inline de voz com indicadores de fala e compartilhamento

3.4 Chat de Texto

Completo
  • Header com chip fixo "E2EE ligada" inegociável em texto
  • Separador de dias com comportamento sticky no scroll
  • Agrupamento de remetentes consecutivos + citações inline
  • Lightbox de imagens decifradas com zoom e arrasto
  • Autocomplete de @menções e :emojis: + pill "Saltar ao presente"

3.5 Voz / Vídeo & Streaming

Completo
  • Pré-entrada com "Testar vídeo" (padrão de teste) e "Apenas ouvir"
  • Comutador Composição / Grade com ponto de tela
  • Faixa permanente de "E2EE desligada" com fluxo de religar
  • Editor de Cena para Admin (drag-and-drop de assentos 2 a 8)
  • Seletor de blur em tempo real: Nenhum / Leve / Forte

3.6 Shell Persistente

Completo
  • Rail de servidores com badge de voz e não lidos
  • Topbar com pesquisa expandível e alternador Sistema/Claro/Escuro
  • Painel do Usuário na base da sidebar com controles de chamada dedicados
  • Popover de conta com edição de Display Name e alternador PT-BR / EN
  • PiP flutuante de chamada arrastável com snap nos 4 cantos
