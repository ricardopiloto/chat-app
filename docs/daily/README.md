# Diário de trabalho (`docs/daily/`)

Um ficheiro por dia: `yyyy-mm-dd.md`.

## Quando actualizar

Sempre que um **`/speckit-implement`** (feature Speckit) for concluído:

1. Criar ou acrescentar a entrada do dia em `docs/daily/yyyy-mm-dd.md`
2. Actualizar `CHANGELOG.md` na secção `[Unreleased]`

Ver também a regra do projecto (local) `.cursor/rules/changelog-and-daily.mdc` e o skill `speckit-implement`.

## Formato sugerido

```markdown
# Daily — YYYY-MM-DD

## Speckit implement

### [NNN-feature-slug](../../specs/NNN-feature-slug/)

- Entrega: …
- Validação: …
```
